# Presensi Sambung

Aplikasi presensi kegiatan **sambung** dan **musyawaroh** (Kelompok · Desa · Daerah) untuk Penerobos — dibuat untuk HP, bisa dipasang seperti aplikasi, dan tetap jalan tanpa internet.

- Centang presensi instan, tab Laki-laki / Perempuan, cari nama, tersimpan otomatis (draft)
- **Musyawaroh**: dapukan (Pak Yai, Wakil Yai, Penerobos, Aghnia, …) diatur Penerobos Utama, anggota dari Data Peserta, **notulen** hasil musyawaroh → salin ke WA atau PDF
- Dua Penerobos bisa mengabsen kegiatan yang sama bersamaan; sinkron ke Google Sheets saat online
- Impor peserta dari Excel, laporan WhatsApp dengan template, PDF di Google Drive, foto kegiatan
- Dashboard kehadiran, mode terang / gelap, **warna aplikasi** pilihan Penerobos Utama
- **Satu situs banyak kelompok**: tiap kelompok punya server & data sendiri, masuk dengan **Kode Kelompok** (`kelola.html`)
- **PWA**: tombol *Pasang aplikasi*, banner *Versi baru tersedia*, terbuka instan & offline

**Teknologi:** HTML/CSS/JavaScript murni (PWA) di GitHub Pages · Google Apps Script sebagai REST API · Google Sheets & Drive.
